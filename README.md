# Azure Data Engineering ETL Project

## Project Overview

Built a Medallion Architecture ETL pipeline using PySpark.

## Architecture

Raw Data → Bronze → Silver → Gold

## Technologies Used

- Azure Data Lake
- PySpark
- SQL
- Power BI

## Project Workflow

1. Ingest CSV
2. Create Bronze Layer
3. Clean Data in Silver Layer
4. Aggregate Data in Gold Layer
5. Validate Using SQL
